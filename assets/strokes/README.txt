zh_hanzi.json: stroke order (centre lines) of the Mandarin hanzi in the lessons.

Derived from Make Me a Hanzi (https://github.com/skishore/makemeahanzi) via
hanzi-writer-data (https://github.com/chanind/hanzi-writer-data). The outlines
come from fonts by Arphic Technology Co., Ltd., released under the Arphic
Public License; the licence text is in ARPHICPL.TXT.
This file is a modified version of that data: only each stroke's centre line is
kept, and coordinates are rescaled to a 109 x 109 grid. Regenerate with
tool/gen_hanzi_strokes.py.
